# Notes for AI coding agents

## Keep personal and machine details out of this repository

Applies to files, commit messages, branch names, pull request titles and descriptions, and any session or tool links.

- Never name the repository owner, use their initials, or include their email address. Write "the maintainer".
- Never name the owner's machines, servers or hosts, or include private IP addresses, hostnames or local filesystem paths. Describe the role instead ("the GPU machine", "the server", "the seedbox") or leave it out.
- Commit only as `Dead Internet Choir <deadinternetchoir@users.noreply.github.com>`.
- Do not add links to agent or chat sessions.
- Before pushing, search the diff for any of the above.

History cannot be fully cleaned once it is pushed (pull request refs and cached views persist), so check before pushing rather than after.
